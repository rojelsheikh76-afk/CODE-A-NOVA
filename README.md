# CODE-A-NOVA — Python Development Internship

Month 2 internship projects for Python Development.

## Projects

### Level 1

1. Rule-Based Chatbot
   - File: `chatbot/chatbot.py`
   - A terminal-based chatbot using predefined rules and conditions.
   - Supports greetings, help, name memory, and exit commands.

2. File Organizer Automation Tool
   - File: `file_organizer/organizer.py`
   - Organizes files into folders based on their extensions.
   - Handles images, documents, videos, audio, code, and other files.
   - Avoids overwriting files with duplicate names.

### Level 2

3. Simple Banking System
   - File: `banking_system/banking.py`
   - Supports account creation, PIN authentication, deposits,
     withdrawals, balance checking, and transaction history.
   - Demonstrates Python classes and methods.

## Requirements

- Python 3.10 or later
- No third-party packages required

## How to Run

### Chatbot
python3 chatbot/chatbot.py

### File Organizer
python3 file_organizer/organizer.py

### Banking System
python3 banking_system/banking.py

## Disclaimer

These projects are educational demonstrations.
The banking application is not intended for real financial transactions.
